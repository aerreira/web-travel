# Bolt's Journal\n\n## Scroll Event Throttling\n- Learned that for this project, adding a throttle function with a trailing edge (using `setTimeout`) is critical for scroll events (like sticky navbars and back-to-top buttons) to ensure the UI updates one final time after the user stops scrolling. A 50ms delay for high-priority UI updates and 100ms for secondary UI elements are ideal.\n- Lazily caching jQuery selectors inside these throttled handlers prevents repeated DOM traversals while ensuring the DOM is ready.\n
