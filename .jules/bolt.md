- **Consolidated Scroll Events**: In `js/main.js`, multiple `$(window).scroll()` event handlers were present for different UI components (sticky navbar and back-to-top button). This is a common performance anti-pattern. Consolidating them into a single, unified listener with lazy selector caching and a 50ms true throttle drastically reduces event binding overhead and repeated DOM traversals on high-frequency scroll events without negatively impacting the UI responsiveness.
